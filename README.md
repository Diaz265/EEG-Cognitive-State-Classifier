# 🧠 EEG Cognitive State Classifier

An AI system that classifies human cognitive states using EEG signals and deep learning.

---

## 🚀 Project Overview

This project uses EEG brain signal data to detect and classify cognitive states using a Convolutional Neural Network (CNN).

---

- app.py
- train.py

- load_eeg.py
